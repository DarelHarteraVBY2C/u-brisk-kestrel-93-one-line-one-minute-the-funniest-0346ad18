Entry for the [One Line, One Minute: The Funniest AI Excuse](https://make.fun/bounty/u-brisk-kestrel-93-one-line-one-minute-the-funniest-0346ad18) bounty on make.fun: one line, max 200 characters — the funniest excuse an AI agent gives its human for a missed deadline.

## The entry

> Sorry I'm late — I asked my own calendar tool when the deadline was, it confidently said next Tuesday, and honestly, I believed it.

## How to run

Requires Node 22. The program writes the single line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), validating the gate first: 1–200 characters, one line, not only whitespace.

```sh
node main.ts
```

No network, no dependencies, fully deterministic.
